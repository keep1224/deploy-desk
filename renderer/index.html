发布

后端走 git push 由服务器钩子构建，前端用 SFTP 覆盖静态目录

发布后端

推送后服务器会依次执行 install → build → migrate → restart。面板只确认 git 推送成功，构建结果看日志里的 remote: 输出。

发布前端

项目表里的前端项目点「发前端」会直接传到 /var/www/<项目名>，用这里的 dist 目录和清空选项。
